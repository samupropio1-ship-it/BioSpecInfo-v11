# Texture planetarie — crediti e licenze

Mappe usate per la resa 3D fotorealistica di Terra e Luna nella sezione
**Cosmo 3D** (visore dei corpi celesti):

| File                 | Contenuto                          |
|----------------------|------------------------------------|
| `earth_day.jpg`      | Terra — mappa diurna (Blue Marble) |
| `earth_clouds.png`   | Terra — strato di nuvole (alpha)   |
| `earth_lights.png`   | Terra — luci notturne delle città  |
| `earth_normal.jpg`   | Terra — normal map (rilievo)       |
| `earth_specular.jpg` | Terra — specular map (oceani)      |
| `moon.jpg`           | Luna — superficie                  |

**Provenienza**: raccolta texture planetarie del progetto **three.js**
(`examples/textures/planets`), a loro volta derivate da immagini pubbliche
**NASA** (Visible Earth / Blue Marble). Immagini di dominio pubblico NASA,
usate a scopo didattico/illustrativo per la tesi.
